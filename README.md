# Pet Store 🐾

This project was created to support **animal rescue efforts** by providing a platform to manage pets, adoptions, and related services.

## 📂 Project Structure
- **Client/** – Frontend code (likely built with HTML, CSS, JavaScript or a framework).
- **Server/** – Backend code (handles APIs, database, and business logic).

## 🚀 Features
- Register rescued animals with details (name, age, breed, health status).
- Manage adoption requests and approvals.
- Track medical records and vaccinations.
- Simple UI for volunteers and adopters.
